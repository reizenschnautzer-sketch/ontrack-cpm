# OnTrack Clinical Project Management

Готовый статический лендинг для https://ontrack-cpm.com/.
Сборка, npm, серверная часть и JavaScript не нужны. Все ресурсы включены: логотип, шрифт и стили. Страница работает и при открытии index.html локально.

## Что внутри

- `index.html` — английский текст и структура страницы.
- `styles.css` — тёмно-синяя тема, адаптивная вёрстка, типографика.
- `assets/ontrack-logo.png` — последняя версия логотипа, без изменений.
- `assets/anton.ttf` — локальный шрифт Anton, запасной вариант для Impact.
- `assets/Anton-OFL.txt` — лицензия шрифта; оставьте в комплекте.
- `assets/favicon.svg` — иконка вкладки.
- `CNAME` — ontrack-cpm.com.
- `.nojekyll` — отключение обработки Jekyll.
- `robots.txt`, `sitemap.xml` — индексация сайта.
- `404.html` — страница отсутствующего адреса.

В заголовках используется Impact при его наличии, затем включённый Anton. В длинном тексте — Arial/Helvetica для удобства чтения. Логотип размещён на белой подложке, поскольку исходное изображение имеет белый фон.

## 1. Загрузить на GitHub

1. Распакуйте архив.
2. Создайте на GitHub репозиторий, например `ontrack-cpm`. Для GitHub Free используйте Public. Загруженные в публичный репозиторий файлы будут общедоступны.
3. Откройте **Add file → Upload files** и загрузите СОДЕРЖИМОЕ папки `ontrack-cpm`, включая папку `assets`. Не загружайте сам ZIP.
4. Убедитесь, что `index.html`, `styles.css` и `CNAME` находятся прямо в корне репозитория, а не во вложенной папке.
5. Сохраните изменения через **Commit changes** в ветку `main`.
6. Если файловый менеджер скрыл `.nojekyll`, создайте пустой файл с таким именем через **Add file → Create new file**.
7. Откройте **Settings → Pages**. В **Build and deployment** выберите **Deploy from a branch**, ветку **main**, каталог **/(root)** и **Save**.
8. В **Custom domain** укажите `ontrack-cpm.com` и сохраните. Сначала настройте домен на стороне GitHub, затем DNS.

## 2. Подключить домен Porkbun

В Porkbun: **Account → Domain Management → ontrack-cpm.com → DNS**.

Вариант через **Quick DNS Config → Github** описан в официальной инструкции ниже. Для ручной настройки используйте следующие записи:

| Type | Host в Porkbun | Answer / Value |
|---|---|---|
| A | оставить пустым (корень домена) | 185.199.108.153 |
| A | оставить пустым (корень домена) | 185.199.109.153 |
| A | оставить пустым (корень домена) | 185.199.110.153 |
| A | оставить пустым (корень домена) | 185.199.111.153 |
| CNAME | www | YOUR-GITHUB-USERNAME.github.io |

Замените `YOUR-GITHUB-USERNAME` своим логином GitHub (или названием организации, которой принадлежит репозиторий). Не добавляйте https:// и имя репозитория. TTL можно оставить по умолчанию.

Удалите только конфликтующие веб-записи для корня домена или www, например парковочный ALIAS/A/CNAME. Почтовые MX и TXT (SPF/DKIM/DMARC), а также записи других сервисов сохраняйте. Не удаляйте все DNS-записи целиком.

После обновления DNS вернитесь в **GitHub → Settings → Pages**. Дождитесь успешной проверки домена и доступности **Enforce HTTPS**, затем включите её. Распространение DNS и подготовка HTTPS могут занять до 24 часов.

При необходимости подтвердите владение доменом в настройках аккаунта GitHub → Pages, добавив выданную GitHub TXT-запись. Её значение индивидуально и не включено в этот комплект.

## 3. Настроить почту

Кнопки сайта открывают почтовое приложение посетителя с адресом `info@ontrack-cpm.com`.
GitHub Pages не создаёт почтовый ящик и не принимает письма. Создайте этот адрес у выбранного почтового провайдера или настройте пересылку и добавьте его DNS-записи. Проверьте получение тестового письма с внешнего адреса. Для ответа от имени info@ontrack-cpm.com требуется поддержка отправки у провайдера.

## 4. Проверить после публикации

- Открываются https://ontrack-cpm.com/ и https://www.ontrack-cpm.com/.
- HTTPS работает; www перенаправляется на основной адрес.
- Логотип отображается, шрифт загружается.
- Навигация ведёт к разделам, email-кнопки открывают письмо.
- Страница удобна на телефоне.
- Письма на info@ontrack-cpm.com действительно приходят.

## Редактирование

Меняйте текст в `index.html`, оформление — в `styles.css`. Цвета заданы в начале CSS. Публикация обновляется после commit в main. При замене логотипа сохраните путь `assets/ontrack-logo.png`.

Страница не содержит формы отправки, аналитики, cookies или внешних загрузок шрифтов. Юридические реквизиты и иные необходимые для вашей компании сведения добавляются после их определения.
